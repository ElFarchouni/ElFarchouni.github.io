# PiezoTool v0.0.0

![PiezoTool cover: groundwater level monitoring pipeline](../assets/images/piezotool-cover.png)

## Overview

**From raw pressure loggers to validated groundwater levels.** PiezoTool is the data chain I
designed and built for a groundwater monitoring network in the Ourika sub-basin (Haouz plain,
Marrakech region, Morocco). It converts raw Van Essen Diver pressure records into validated
depth-to-water and piezometric-head series, and packages the method as a no-code Streamlit
application for the field team, complemented by an interactive map-and-chart web console.

**Study area:** Ourika sub-basin, Haouz plain (Morocco)
**Period:** 2024 to 2026
**Role:** Sole designer and developer (method, processing, applications, documentation), within the PhD project
**Status:** Ongoing (first public version of this page, v0.0.0)

`Python` `pandas` `Jupyter` `Google Earth Engine` `ERA5-Land` `Streamlit` `Leaflet` `Chart.js`
